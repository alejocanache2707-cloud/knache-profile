# Knache Profile

Proyecto de landing page personal con una estructura simple y moderna.

## Estructura
- `index.html`
- `css/style.css`
- `js/script.js`

## Cómo usar
1. Abre `index.html` en el navegador.
2. Personaliza el texto con tus datos.
3. Ajusta colores, secciones y contenido según tu perfil.

## Personalización recomendada
- Cambia el nombre "Knache" por tu nombre.
- Actualiza el email, los proyectos y las habilidades.
- Añade tu avatar, redes sociales o enlaces a GitHub/LinkedIn.

## Tecnologías
- HTML
- CSS
- JavaScript
