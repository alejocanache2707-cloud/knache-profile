# Carpeta de imágenes

Guarda aquí todas las imágenes que usará la página del perfil.

Ejemplo de uso en HTML:

```html
<img src="assets/images/mi-foto.jpg" alt="Mi foto" />
```

Sugerencias:
- usa nombres descriptivos en minúsculas
- usa formato web optimizado: .jpg, .jpeg, .png, .webp
- mantén tamaños moderados para mejor rendimiento
